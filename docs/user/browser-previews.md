# Browser previews

CPH Code keeps browser previews out of the transcript so they do not cover the conversation while you read or direct an agent.

Agent browser tools still run against the desktop browser host in the background. They can navigate pages, inspect them, take screenshots, and make recordings without opening a floating mini-player over chat.

When you want to see the browser yourself, open its preview in the right panel. The desktop preview menu can also move it into a separate native window; neither presentation overlays the transcript.
